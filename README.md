# MH Sort

Сортировщик файлов для Windows. Раскладывает содержимое папки (например, «Загрузки») по папкам категорий: `Изображения`, `Видео`, `Документы`, `Архивы` и так далее, а внутри них — по типам: `Видео\MP4`, `Видео\MKV`.

Написан на Rust с интерфейсом на [egui](https://github.com/emilk/egui). Один exe, установка не нужна.

## Возможности

- **Предпросмотр.** Перед сортировкой видно, какой файл куда ляжет. Можно снять отметку с отдельных файлов или целых категорий, искать по имени.
- **Перемещение или копирование.** Результат можно сложить в исходную папку или в любую другую.
- **Отмена.** Каждая операция пишется в журнал, последнюю можно отменить одной кнопкой. Хранятся последние 100 журналов.
- **Определение типа по содержимому** для файлов без расширения или с незнакомым расширением.
- **Без конфликтов имён.** Если в папке назначения уже есть файл с таким именем, новый получает номер.
- **Безопасные пропуски.** Не трогает скрытые и системные файлы, недокачанные загрузки (`.crdownload`, `.part`, `.!ut` и т. п.), уже разложенные папки и папки из списка исключений.
- **Подпапки.** Можно разбирать вложенные папки и удалять те, что опустели после перемещения.
- **Drag & drop.** Папку можно перетащить в окно или на `mh-sort.exe`.
- **Настраиваемые категории** в файле `categories.json`.

## Установка

Скачайте `mh-sort.exe` со страницы [Releases](https://github.com/midnightheartsgames/MH-Sort/releases/latest) и запустите.

## Категории

По умолчанию есть 18 категорий: Изображения, Видео, Аудио, Документы, Книги, Таблицы, Презентации, Архивы, Образы дисков, 3D, Проекты, Код, Игровые ресурсы, Программы, AI модели, Торренты, Шрифты, Ярлыки. Всё остальное попадает в `Прочее`.

Категории хранятся в `categories.json`. Открыть его можно из окна настроек, после правки нажмите «Перечитать». Формат:

```json
{
  "unknown_category": "Прочее",
  "no_extension_folder": "Без расширения",
  "ignore_extensions": ["crdownload", "part", "tmp"],
  "categories": {
    "Изображения": ["jpg", "png", "webp"],
    "Архивы": ["zip", "7z", "tar.gz"]
  }
}
```

Поддерживаются составные расширения вроде `tar.gz`. Если расширение указано в двух категориях, используется первая.

## Где хранятся настройки

- Обычно — `%APPDATA%\MH Sort\` (`categories.json`, `settings.json`, папка `history` с журналами).
- **Портативный режим:** если рядом с `mh-sort.exe` лежит `categories.json`, все файлы программы хранятся рядом с exe.

## Сборка из исходников

Нужен [Rust](https://rustup.rs/) 1.87+ (edition 2024).

```bash
cargo build --release
```

Готовый файл: `target/release/mh-sort.exe`. Иконка встраивается в exe на Windows (MSVC) скриптом `build.rs`, `rc.exe` не нужен.

Тесты:

```bash
cargo test
```
